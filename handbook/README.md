# HTR Handbook Files

Place Holidays That Rock parent handbook PDF(s) in this directory. They are uploaded automatically to each new booking's `Handbooks/` Google Drive subfolder when a camp folder is created.

## Expected files

- `parent-hotr-handbook.pdf` (or any `.pdf` files in this folder)

All PDF files in this directory are uploaded on folder creation. If no PDFs are present, the folder is still created but a warning is logged.
